Комплексное решение для создания и проверки одноразовых паролей (OTP), обеспечивающее доставку по нескольким каналам.

Стэк: java 22, Maven, PostgreSQL 15, HMAC-SHA1, Base32, JavaMail API, jSMPP, TelegramBots Java Library, Файловая система + ZIP-архивация

Функционал: Генерация TOTP (Time-based OTP) по стандарту RFC 6238, поддержка различных каналов доставки (Email, SMS, Telegram бот, Файловый лог), двухуровневая система доступа 
(администраторы, обычные пользователи), аудит операций (База данных PostgreSQL, файловые логи, история генераций и проверок)
